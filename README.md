# Corpus congelado — 2º passe de codificação

Os documentos auditados, congelados no estado sobre o qual a codificação é
feita. Servido online para o segundo avaliador ler direto do instrumento, sem
baixar nem descompactar nada.

**Este repositório é privado e permanece privado.** São 143 políticas de
plataforma reproduzidas na íntegra para uso em pesquisa; o pacote de replicação
público leva apenas os hashes e as URLs de origem, nunca os documentos.

Gerado por `analysis/freeze-sources.py package` do repositório do instrumento —
não editar à mão. Cada arquivo abre com sua procedência (URL, data, vantagem,
método) e o SHA-256 do corpo.

Ver `LEIA-ME.md` para o método de extração e o que ele implica na codificação.
